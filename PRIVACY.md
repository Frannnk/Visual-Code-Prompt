# Visual Code Prompt Privacy Policy

**Effective date: September 5, 2026**

Visual Code Prompt is a Chrome extension for selecting elements on a live webpage,
reviewing their rendered layout and styles, and generating an edit prompt for an
AI agent or developer.

## Data use

Visual Code Prompt does **not** collect, store, sell, or share personal data.

The extension does not use analytics, advertising, tracking pixels, cookies,
remote AI services, or external servers. It does not send webpage content,
source code, form values, or selected-element details outside the current browser
tab.

## What the extension can access

When the user activates the extension on a webpage, it reads the page DOM,
rendered dimensions, and computed styles locally in that tab so the user can
select and inspect an element. The user can enter notes and copy a generated
prompt to the clipboard. These operations stay on the user's device.

Runtime edits are temporary. They exist only in the current page session and are
discarded when the page is refreshed or the extension overlay is closed.

## Changes to this policy

If the extension's data practices change, this policy will be updated before the
change takes effect. The effective date above will also be updated.
